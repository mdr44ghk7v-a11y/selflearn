# 智光商工 資料處理科 一年仁班
## 「新北市技術型高中自主學習 Go AI 成果競賽」班級意願調查與分類統計系統

本系統已全面更新為**資處一仁專屬版本**，完美實現**「分類哪些人要參加、哪些人不參加、哪些座號尚未填寫」**的班級統計需求！

---

### 🌟 新增三大核心升級（交差給老師的秘密武器）

#### 1. 雙向意願登記（要參加 vs 不參加）
- **✅ 我要參加**：
  - 展開組別選擇（「行動 Go AI 組」或「技能 Book 組」）。
  - 填寫預計題目、使用的 AI 工具（ChatGPT / Gemini / NotebookLM / Napkin 等）、指導老師與聯絡方式。
- **❌ 我暫不參加**：
  - 展開原因下拉選單（例如：專注準備電腦軟體應用乙/丙級檢定、專注文書處理/段考課業、尚無合適主題等）。
  - 讓老師清楚知道全班每位同學目前的方向與考量，而不是只有已報名的人。

#### 2. 即時分類名冊與頁籤切換（Tabs）
- 點擊上方按鈕即可一秒切換查看：
  - **全部已填**：總覽全班所有回覆名單。
  - **🟢 要參加**：只看參賽名單與作品方向。
  - **🔴 不參加**：只看暫不參賽的同學與各自原因。
  - **📘 技能 Book 組** / **🤖 行動 Go AI 組**：細部組別篩選。

#### 3. 尚未填寫座號追蹤器（班級幹部催收神器）
- 頁面下方有專門的「**尚未完成填寫同學名單**」：
  - 系統自動計算全班人數（預設 38 人，可點齒輪自訂），即時抓出哪些座號**還沒上線登記**！
  - 點擊「**複製未填座號提醒**」，一秒複製整齊的 LINE 催繳訊息（例如：「*📢 目前以下座號尚未完成登記：5、9、14... 請儘速填寫！*」），直接貼班群超省事！

#### 4. Excel 匯出與 LINE 名單自動分類
- **一鍵匯出 Excel (CSV)**：內含「意願狀態」與「不參加原因」欄位，UTF-8 BOM 防亂碼格式，微軟 Excel 雙擊直接開啟。
- **一鍵複製 LINE 名冊**：自動整理成三區塊：
  - 【確認要參加同學名單】
  - 【不參加同學名單】
  - 【尚未填寫座號】

### 🖥️ 如何使用？

1. **本機直接打開測試**：
   - 瀏覽器網址列貼上：
     ```text
     file:///C:/Users/lijin/Desktop/uuuu/index.html
     ```
   - 預設已有 5 筆「資處一仁」示範資料（含要參加與不參加），可以隨時點「資料選項」載入或清空。

2. **發給全班同學填寫（公開網址）**：
   - 到 [https://app.netlify.com/drop](https://app.netlify.com/drop)，將桌面上的 `uuuu` 資料夾拖進去，即可免費取得手機可開的網址！
